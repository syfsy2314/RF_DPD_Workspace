# 有效激励与 H1 通带相位修正的 H2 覆盖对照

实测 PA 输入输出 38400 点，Fs=1000 MHz。H1 为 13 阶椭圆 IIR，通带/阻带边缘 85/90 MHz，通带波纹 0.1 dB。H2 通带边缘 80 MHz，阶数 1109。

令 y_f=H1(y)。开关 2 绕过 PA，得到 x_BL=H1(x)，先由 x,x_BL 训练反馈链残余相位；切回开关 1 后，实际 PA 反馈保持 H2*H1(y)，训练得到的相位 FIR 仅在模型侧与 H2 卷积覆盖。另由 x,y_f 互谱估计相位。离线参考用真实 y 与原始 y_f 拟合 2048 抽头完整复数 FIR，但只提取相位。局部三组修正约 ±49 MHz；宽频组使用同一 y,y_f 算子修正至 ±80 MHz，并在 80–85 MHz 过渡归零。各相位组使用相同的 4001 抽头纯相位 FIR 构造方法。前五组使用同一份 H2 80 MHz 后反馈；后四组使用同一份 H2 44 MHz 后反馈。九组使用相同 LD-PLS 参数，并在样本 5001–33400 上评分。输入 x 的可靠激励始终约为 ±49 MHz；宽频组扩展的是离线相位修正范围，并非输入激励范围。开关 2 是 PA 旁路校准，不是实际功率回退数据。

| 方法 | PA 全带恢复 NMSE |
|---|---:|
| 仅 H2 80 MHz 覆盖 | -19.27 dB |
| x,y_f：相位约 ±49 MHz + H2 80 MHz 覆盖 | -20.22 dB |
| 开关 2：x,x_BL 训练相位 + H2 80 MHz 模型侧覆盖 | -20.19 dB |
| y,y_f：相位约 ±49 MHz + H2 80 MHz 覆盖 | -20.19 dB |
| y,y_f：相位修正至 ±80 MHz + H2 80 MHz 覆盖 | -38.42 dB |
| x,y_f：相位约 ±49 MHz + H2 44 MHz 覆盖 | -32.94 dB |
| 开关 2：x,x_BL 训练相位 + H2 44 MHz 模型侧覆盖 | -37.01 dB |
| y,y_f：相位约 ±49 MHz + H2 44 MHz 覆盖 | -37.02 dB |
| y,y_f：相位修正至 ±80 MHz + H2 44 MHz 覆盖 | -37.39 dB |

## 相同输入记录下的相位修正范围与 H2 带宽对比

同一条 x、y 实测记录保持不变，x 的可靠激励边缘实测为 48.83 MHz；窄 H2 通带/阻带边缘为 44/47 MHz，阶数 1109。物理反馈和模型侧覆盖均使用对应的 H2；宽频 y,y_f 组把离线相位修正扩展至 ±80 MHz，输入激励没有变宽。所有组保持 LD-PLS 参数和评分样本一致，不增加过拟合处理。

| 相位来源与修正范围 | H2 通带 | PA 全带恢复 NMSE |
|---|---:|---:|
| x,y_f；相位约 ±49 MHz | ±44 MHz | -32.94 dB |
| x,y_f；相位约 ±49 MHz | ±80 MHz | -20.22 dB |
| 开关 2；x,x_BL 训练相位约 ±49 MHz | ±44 MHz | -37.01 dB |
| 开关 2；x,x_BL 训练相位约 ±49 MHz | ±80 MHz | -20.19 dB |
| y,y_f；相位约 ±49 MHz | ±44 MHz | -37.02 dB |
| y,y_f；相位约 ±49 MHz | ±80 MHz | -20.19 dB |
| y,y_f；相位至 ±80 MHz | ±44 MHz | -37.39 dB |
| y,y_f；相位至 ±80 MHz | ±80 MHz | -38.42 dB |

与 H2 80 MHz 相比，H2 44 MHz 下相同局部相位修正的 NMSE 变化 -12.73 dB；负值表示改善。仅 H2 覆盖的诊断值分别为 -17.37 dB（44 MHz）和 -19.27 dB（80 MHz）。

H2 44 MHz 下，y,y_f 局部相位修正相对 x,y_f 局部相位修正的 NMSE 变化 -4.07 dB。

固定 H2 44 MHz 时，y,y_f 宽频相位修正相对约 ±49 MHz 相位修正的 NMSE 变化 -0.37 dB；固定宽频相位修正时，H2 44 MHz 相对 H2 80 MHz 的 NMSE 变化 1.03 dB。负值表示改善。

局部相位 FIR 在可靠激励边缘的 5 MHz 内逐渐归零；宽频相位 FIR 则继续修正 H2 44 MHz 通带边缘。两者在 39–44 MHz 的相位差 RMS 为 0.03 度。

固定 H2 80 MHz 时，y,y_f 相位修正由约 ±49 MHz 扩展至 ±80 MHz 后，NMSE 改善 18.23 dB。x,y_f 局部相位修正比 y,y_f 局部相位修正差 -0.03 dB。

x,y_f 相位修正使 NMSE 改善 0.94 dB；三个相位 FIR 在各自设计频段的最大幅度偏差分别为 0.000、0.000 和 0.038 dB，其中宽频段相位 FIR 在 H2 的 ±80 MHz 内为 0.006 dB。

x,y_f 与 y,y_f 在相同有效激励频点的残余相位差 RMS 为 0.01549 rad；y,y_f 相位修正比 x,y_f 相位修正的恢复 NMSE 低 -0.03 dB。

开关 2 训练相位与 y,y_f 离线相位在相同频点的残余相位差 RMS 为 0.001127 rad。H2 44 MHz 下，开关 2 模型侧相位补偿比 x,y_f 相位估计的 NMSE 改善 4.06 dB，与 y,y_f 局部离线参考相差 0.01 dB。

y,y_f 完整算子对 y_f 的时域拟合 NMSE 为 -99.31 dB，H2 通带内相对真实 H1 的残余相位误差 RMS 为 0.00008 rad；拟合长度 2048 抽头、岭参数 1e-06。y,y_f 各组只用该算子的相位，幅度不进入模型侧覆盖；算子拟合使用真实 y，不能解释为仅凭 x,y_f 可实现的盲校准。

x,y_f 相位仅在 -48.83 至 48.83 MHz 的有效激励频段估计，频段边缘外的修正逐渐归零；±85 MHz 组的相位来自真实 y,y_f 拟合算子，并非 x,y_f 的全带估计。

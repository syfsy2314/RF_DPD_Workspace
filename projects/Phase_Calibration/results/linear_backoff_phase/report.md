# 理想线性区 x,x_f 相位校准

令 x_f=H1(x)，模拟 PA 严格线性且无残余动态相位的校准记录。H1 为 13 阶椭圆 IIR，85/90 MHz，波纹 0.1 dB；H2 45/48 MHz。使用同一 38400 点实测输入，Fs=1 GHz；只由 x,x_f 选择可靠频点并估相位。该实验并非真实低功率 PA 测量。

Welch 4096 点 Hann 窗、2048 点重叠、8192 点 FFT、5 点平滑；门限为输入功率 ≥ 峰值 −30 dB、相干度 ≥ 0.8。实际频率 -48.83 至 48.83 MHz。相位 FIR 4001 抽头、边缘 5 MHz 归零；各组均为纯相位模型与 H2 覆盖。

| 相位来源 | 对 H1 真值误差 RMS (rad) | 度 |
|---|---:|---:|
| x,y_f | 0.015495 | 0.8878 |
| x,x_f | 0.001132 | 0.0648 |
| y,y_f 离线算子 | 0.000006 | 0.0003 |
| H1 真值 | 0.000000 | 0.0000 |

将校准相位应用于实测 PA 的 y_f，LD-PLS 参数 K=7、M=5、S=0.3、lamda=1，统一在样本 5001–33400 评分；真实 y 不进入 x,x_f 相位估计。

| 方法 | 真实 PA 全带恢复 NMSE (dB) |
|---|---:|
| 仅 H2 45 MHz | -15.22 |
| x,y_f ； 相位 ±49 ； H2 45 | -31.28 |
| x,x_f ； 相位 ±49 ； H2 45 | -35.61 |
| y,y_f ； 相位 ±49 ； H2 45 | -35.63 |
| 真实 H1 相位 ±49 ； H2 45 | -35.63 |

线性链路自身恢复 x 的 NMSE：仅 H2 -15.52 dB；x,x_f 校准相位 -41.56 dB；真实 H1 相位 -41.63 dB。

x,x_f 校准相对 x,y_f 校准的真实 PA 恢复 NMSE 变化 -4.33 dB，与 y,y_f 离线参考相差 0.02 dB。

该设置完全去除了 PA 本身的相位；真实 PA 即使回退到线性区，也可能保留线性记忆相位，实际低功率校准仍需验证这部分残余。

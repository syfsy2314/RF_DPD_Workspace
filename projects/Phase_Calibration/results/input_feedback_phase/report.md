# 输入与带限反馈的 H1 残余相位验证

## 实验设置

实测 PA 输入输出 38400 点，Fs=1000 MHz；H1 为 13 阶椭圆 IIR，通带/阻带边缘 85/90 MHz，通带波纹 0.1 dB，阻带衰减 80 dB。z=H1(y)，无 H2。

对齐后首尾各去除 5000 点。Welch 分段 4096 点 Hann 窗、重叠 2048 点、NFFT=8192；互谱和功率谱再作 5 频点移动平均。

估计频点预设门限：输入功率相对峰值 ≥ -30 dB、x,z 相干度 ≥ 0.8。离线评价再限制于 H1 的 ±85 MHz、幅度 ≥ −1 dB 通带。所有相位在同一频点展开，再分别去除最佳常相位与线性时延。

## 实测结果

- 可靠频率：-48.83 至 48.83 MHz；801/1393 个通带频点，覆盖 57.5%。
- PA BLA 残余相位 RMS：0.01556 rad (0.89°)。
- H1 真实残余相位 RMS：0.07158 rad (4.10°)。
- 已观测频段 H1 估计误差 RMS：0.01549 rad (0.89°)，为该频段真值残余相位 RMS 的 21.6%；门限 0.10 rad，达到。
- 频谱估计偏差 RMS：0.00113 rad；y,z 离线滤波器相位检查 RMS：0.00110 rad。
- PA 与频谱偏差的二倍交叉项：-0.000003 rad²；两项可相互增强或抵消。

误差分解采用同一去线性算子：估计误差 = PA BLA 残余相位 + 频谱估计偏差。后者由 x,z 与 x,y 的离线差值得到；y,z 互谱提供独立检查。

## 判断

PA 残余相位 RMS 约为已观测频段 H1 真实残余相位的 21.7%；按分量 RMS 比较，本次主要误差来源为PA 自身残余相位。x,z 的估计在已观测频段达到 0.10 rad 门限。现有 x 在通带外侧缺乏可靠激励，完整 ±85 MHz 通带尚未验证；不能据此判定全通带估计成功，也不开展联合校准。需要覆盖整个通带的实测 x,y 记录。

本次结果只覆盖一条实测 PA 记录和一个 H1 设计，可靠频段之外不作相位推断。

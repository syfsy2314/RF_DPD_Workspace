# 开关 2 相位与幅度同步校准结果

输入为 datasets/测试/2026.6.10/test1/ 中同一条实测 x、y0，采样率 1 GHz。开关 2 只用 x 与 x_f=H1(x) 训练；开关 1 的真实反馈为 H2(H1(y0))。H1 是 85/90 MHz、80 dB 阻带衰减、1 dB 通带波纹的 12 阶椭圆 IIR。H2 通带边缘分别为 80 MHz 和 44 MHz。

互谱使用 4096 点 Hann 窗、2048 点重叠、8192 点 FFT 和 5 频点平滑。相位和幅度使用相同可靠频点，范围为 −48.95 至 48.71 MHz；频段边缘 5 MHz 内逐渐退回单位响应。PA 恢复使用相同的 K=7、M=5、S=0.3、lamda=1 的 LD-PLS，在样本 5001–33400 上评分。NMSE 越负越好。

| 模型侧反馈算子 | H2 80 MHz | H2 44 MHz |
|---|---:|---:|
| 仅 H2 | −20.08 dB | −17.98 dB |
| 开关 2 相位 | −20.52 dB | −27.39 dB |
| 开关 2 相位+幅度 | −20.99 dB | −37.05 dB |
| 已知 H1 参考 | −38.80 dB | −37.22 dB |

开关 2 观测相对真实 H1 的可靠频段幅度 RMS 误差为 0.0091 dB，残余相位 RMS 误差为 0.00223 rad。H2 44 MHz 时，相位+幅度比相位单独校准改善 9.66 dB，与已知 H1 参考仅差 0.17 dB。H2 80 MHz 时仅改善 0.47 dB，仍比参考差 17.81 dB，因为输入 x 无法校准 H1 的整段 80 MHz 通带。

模型侧 FIR 的误差诊断显示：在 |f|≤39 MHz，幅度误差为 0.0076 dB、残余相位误差为 0.0096 rad；在 39<|f|≤44 MHz 的边缘，幅度误差为 0.0110 dB、相位误差为 0.0177 rad。44 MHz 基本落在可靠校准范围内，避开了 5 MHz 退回单位响应处理造成的较大边缘误差；80 MHz 则覆盖大量未由 x 激励的频段。

本次按原 Phase_Calibration/main.m 的实际窄 H2 变量 44 MHz 执行；原脚本注释中的“48 MHz”未改。结果数组和观测曲线保存在 results.mat、calibration_response.png、nmse_comparison.png 与 psd_comparison.png。幅相图的横轴为 H1 的 ±85 MHz 通带，真实响应和模型侧 FIR 覆盖全通带；开关 2 测量值仅在可靠的约 ±49 MHz 内绘制。PSD 图只展示 H2 44 MHz 下的真实 PA 输出、仅相位恢复和相位+幅度恢复，横轴为完整采样频段 ±500 MHz；各路独立归一化到单位 RMS，因而只比较频谱形状，不展示绝对增益。
